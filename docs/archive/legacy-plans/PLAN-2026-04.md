# KyanetWorkStation 项目计划（Current + Next）

## 1. 当前状态（截至 2026-04）

### 已完成能力
- 自托管部署链路：`Node.js + Express + SQLite/MySQL/PostgreSQL + Nginx/IIS/Caddy + PM2`
- 业务模块：反馈提交、WorkTask 提交、管理后台统一面板、主页展示栏
- 管理能力：状态流转、主页显示开关、备注/对外回复、CSV 导出、本人任务录入
- 通知能力：SMTP 通知、Webhook 通知、管理端 SMTP/Webhook 测试入口
- 基础安全：会话 Cookie、限流、输入校验、统一错误响应、CSP、管理写接口来源校验、管理写接口 JSON 限制
- 备份能力：SQLite 在线快照备份（跨平台脚本 + 保留策略）+ MySQL/PostgreSQL 备份脚本
- 可观测性：结构化日志（pino）+ 请求日志（requestId/耗时/状态码）
- 自动化测试：`node:test` 基础测试集（config/validation/security/backup-rdbms）

### 当前默认技术路线
- 运行模式：单实例 `PM2 fork`（低资源优先）
- 数据库：默认 `SQLite`，可切换 `MySQL/PostgreSQL`
- 服务器建议：`2C4G/4C4G` 同机多项目

## 5. 验收标准（通用）

- 功能：反馈/WorkTask 全链路可用且无阻断回归
- 安全：管理接口未登录不可访问；跨站来源写入请求被拒绝
- 运维：可执行备份与恢复；回滚路径明确
- 性能：常规场景 `API P95 < 300ms`，单实例内存控制在目标范围
